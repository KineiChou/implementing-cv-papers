# Learning Roadmap

## Phase 1: The Classics
- [ ] **LeNet-5**: Understand CNN basics, convolutions, pooling.
- [ ] **AlexNet**: ReLU, Dropout, Data Augmentation.
- [ ] **VGG**: Deep networks, 3x3 convolutions.

## Phase 2: Modern Architectures
- [ ] **ResNet**: Residual connections, solving vanishing gradients.
- [ ] **Inception**: Inception modules.

## Phase 3: Beyond Classification
- [ ] **Object Detection**: YOLO, Faster R-CNN (Basic concepts).
- [ ] **RNNs/LSTMs**: Sequence data.
- [ ] **Transformers**: Attention mechanisms.
