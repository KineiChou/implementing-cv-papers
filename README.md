# Deep Learning Models Implementation

This project functions as a personal learning repository for implementing various Deep Learning models from scratch. The goal is to deeply understand the principles and technical details of classic and modern neural networks.

## Structure

- `src/`: Core implementation code.
    - `src/models/`: Model definitions (e.g., LeNet).
    - `src/utils/`: Utility functions.
- `docs/`: Learning notes and documentation.
- `notebooks/`: Jupyter notebooks for experiments and visualizations.
- `tests/`: Unit tests to verify implementations.

## Getting Started

1.  Clone the repository.
2.  Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```
3.  Explore the notebooks or run scripts in `src/`.
